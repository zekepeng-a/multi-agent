# SUPER_AGENT_ROADMAP.md

**Status:** ACTIVE — SA0 RESEARCH / CONSTITUTION ONLY  
**Human direction:** 2026-10-01 — pursue a Super Agent for large complex projects while preventing model drift and avoiding further sunk-cost investment in legacy V0.5.

This roadmap is deliberately narrow. It does not authorize implementation of an Execution Engine.

## SA0 — Constitution & Architecture Archaeology

**Status:** ACTIVE

### Goal

Create a durable, source-grounded product constitution and evidence base before implementation.

### Required outputs

1. `SUPER_AGENT_CONSTITUTION.md` — proposed, challenged, then Human-accepted constitution.
2. `docs/super-agent/REFERENCE_RESEARCH.md` — external precedents and unresolved questions.
3. `docs/super-agent/LEGACY_V05_ASSET_AUDIT.md` — KEEP/REBUILD/DEMOTE/RETIRE/EVIDENCE_ONLY.
4. `SUPER_AGENT_REALITY.md` — current reality only.
5. benchmark/evaluation design comparing simpler and more complex execution strategies.
6. contradiction review against Project Control OS invariants and legacy lessons.

### Allowed work

- read-only repository archaeology;
- external research;
- historical-report forensics if local reports become available;
- constitution drafting/challenge;
- benchmark design;
- candidate architecture sketches clearly marked non-authoritative.

### Not allowed

- new Execution Engine production code;
- V0.5 feature development;
- automatic migration of legacy state/memory;
- treating DSH/Codex/Claude as mandatory product identity;
- accepting multi-agent as default without benchmark evidence;
- modifying Project Control invariants to fit an execution runtime.

### Exit gate

SA0 exits only when:
1. constitution has survived an explicit adversarial/challenge review;
2. legacy audit is sufficiently complete for migration decisions;
3. external research sources are traceable;
4. baseline evaluation plan exists;
5. Project Control compatibility review finds no hidden authority conflict;
6. Human explicitly accepts the constitution and authorizes the next phase.
