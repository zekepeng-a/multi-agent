Its own current-reality labels remain authoritative in `PROJECT_ARCHITECTURE.md`.

## 4. Critical uncertainty

The central open question is not “which multi-agent framework should we use?”

It is:

> What is the minimum architecture that measurably improves large-project completion beyond a strong single-agent + tools + Project Control baseline?

Until that is answered, complexity remains candidate, not capability.
